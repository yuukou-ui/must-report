# 用語と保存データ

言葉の意味がずれると、AIは正しいコードを書いても違うものを作ってしまう。
この仕事で使う言葉と、端末に残しているデータの意味をここにそろえる。

## 仕事の言葉
- **物件**：清掃する建物。報告書1枚＝1物件・1回の清掃。
- **取引先**：物件の清掃を依頼している会社。報告書は取引先ごとにまとめて提出する。
- **清掃者**：現場で清掃し、スマホで報告書ツールを使う人。
- **清掃頻度**（物件ごと）：月2回 `'2'`／月1回 `'1'`。登録していない物件は、出し忘れを見逃さないよう安全側で月2回として扱う。
- **まとめ方**（取引先ごと。一度選べば覚える）
  - `half` 前半・後半に分けて提出 →「○月前半分」（1〜15日の報告書）「○月後半分」（16日以降）
  - `m1` 月1回の提出 →「○月_月1回」
  - `mo` ひと月分まとめて提出 →「○月分」
- **提出の区切り**（まとめツールで選ぶ。取り込んだPDFの清掃日から自動で選ばれる）
  - 前半の提出：`half` の取引先の「前半分」だけを作る
  - 後半・月末の提出：「後半分」「月分」「月_月1回」を作る
- **出し忘れ**：まとめる時点で、その月に必要な回数の報告書がそろっていない物件・取引先。
- **表記ゆれ**：同じ物件が違う書き方で入力されること（全角/半角、空白、ハイフンの種類、「グレース5／V／Ⅴ／五」など）。照合キー `normKey` で吸収する。表示は登録された書き方のまま。
- **別名（エイリアス）**：`normKey` でも吸収できない打ち間違いを、利用者が一度「同じ物件です」と答えたもの。次から自動で正式名に寄せる。
- **まとめる／切り離す**（まとめツール）：別の書き方の物件名を、ある物件の別名にすること／それを取り消して別の物件に戻すこと。
- **物件一覧**：まとめツールで整理した正しい物件名の一覧。`MUST-BUKKEN/1 <件数>` で始まる文字列を LINE 等で渡し、報告書ツールに貼り付けて取り込む。取引先名は含めない。報告書ツールが自分で覚えた履歴とは別枠で持つ。
- **そろそろ**（報告書ツールのチップ）：しばらく報告書を出していない物件を3件、ワンタップ候補として出すもの。
- **定番**（作業内容）：作業内容のタップ項目。端末ごとに追加・削除・並べ替え（つまみ ≡）ができる。報告書には「押した順」に並ぶ。
- **次の報告書へ**：送信後に押すボタン。清掃日・清掃者は引き継ぎ、物件名・特記事項・写真・作業内容のチェックは空にする。
- **検証用ページ／本番**：`preview/`・`matome/preview/` が検証用、それ以外が本番。

## ファイル名の決まり
- 報告書ツールが作るPDF：`物件名_YYYYMMDD.pdf`（物件名も清掃日も空の時だけ `清掃報告書.pdf`）。
  PDFの内部に、subject＝清掃日 `YYYYMMDD`、keywords＝物件名 を埋め込む（見えない情報。LINEでファイル名が変わっても残る）。
- まとめツールが作るPDF：`清掃報告書_<区切り>_【取引先名】.pdf`
  （区切りは `9月前半分` `9月後半分` `9月分` `9月_月1回` のような形）。

## 端末に保存しているデータ
キー名や形を変えると、現場の端末に貯まったものが消えたように見える（CLAUDE.md「必ず守ること」の4）。

### 報告書ツール（スマホ・localStorage）
| キー | 中身 |
|---|---|
| `must_place_history` | 実際にPDFにした物件名の履歴 `[{n:物件名, y:読み(ひらがな)}]`。最大300件。古い形（文字列だけ）も読める |
| `must_place_master` | 取り込んだ物件一覧 `{list:[物件名...], t:取り込んだ時刻}` |
| `must_draft` | 入力途中の控え。半日たつと使わない。写真は容量が大きいので含まない |
| `must_sent` | 今日送った物件の一覧 `{d:日付, list:[...]}`。日付が変わると空に戻る |
| `workItems` | 作業内容の定番リスト（並び順そのまま） |
| `cleanerNames` | 清掃者の名前のワンタップ候補 |

### まとめツール（PC・localStorage）
| キー | 中身 |
|---|---|
| `must_property_map` | 物件名 → 取引先 |
| `must_property_freq` | 物件名 → 清掃頻度 `'2'`／`'1'` |
| `must_property_alias` | 照合キー → 正式な物件名 |
| `must_property_alias_name` | 照合キー → まとめた時の元の書き方（照合キーは画面に出すと別物に見えるため、一覧にはこちらを出す） |
| `must_client_style` | 取引先 → まとめ方 `half`／`m1`／`mo` |
| `must_client_period_style` | 古い版のまとめ方。読み込み時に `must_client_style` へ引き継ぐだけ |

### まとめツール（PC・IndexedDB）
- `must-matome`（検証用ページは `must-matome-preview`）：保存先フォルダの参照。Chrome/Edge だけの仕組みで、文字列にできないので localStorage ではなくこちらに入れている。

### 報告書ツールのキャッシュ（sw.js）
- `must-report-v1`：圏外で使うために保管している画面・部品・アイコン。
